# mtats 0.1.2

Fixes the menu bar indicators disappearing after connecting or disconnecting external displays.

- Menu bar items now have stable names, so macOS remembers where they belong.
- Switching between Normal and Compact reuses the same items instead of recreating them.
- Display changes are given a few seconds to settle before mtats decides whether anything is hidden.
- Old anonymous item state from earlier versions is cleared on first launch.
