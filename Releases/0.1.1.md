# mtats 0.1.1

Indicators fit better, especially on notched Macs.

- New **Compact menu bar** setting: all indicators in one tightly spaced item. Normal (one item per indicator) stays the default.
- Turns on automatically when macOS hides indicators behind the notch.
- Settings stay reachable even when the gear is hidden: reopen mtats, or use the Settings button in any indicator's dropdown.
- Tighter default spacing.
